# Shadow of Justice

## Plugin defaults for this project

At the start of each task, check which enabled plugin skills apply. Read and follow the matching skills automatically when available. The user does not need to name a plugin or skill.

- **Unity** for Editor operations, Unity UI, assets, audio, physics, and other tasks covered by its Unity workflows.
- **Superpowers** for planning substantial changes, debugging, and verifying implementation. Match the workflow to the size and needs of the task.
- **GitNexus** for tracing code, checking dependencies before refactors, and reviewing changes when the project index is available.
- **claude-mem** for recalling previous project decisions or implementation details when they matter to the current task.
- **Humanizer** for revising logbook entries or other prose when the user wants more natural wording.
- **Cloud Environment** for tasks that use a Codex cloud workspace or a shared cloud desktop.

If a matching plugin is unavailable in the current session, use the available tools and continue the task.
